# InviteGen

Gerador de convites personalizados com prévia em tempo real.

![Status](https://img.shields.io/badge/status-Prot%C3%B3tipo%20funcional%20%E2%80%94%20em%20evolu%C3%A7%C3%A3o-blue?style=flat-square)

**Tecnologias:** HTML · CSS · JavaScript · html2canvas

## Sobre

A proposta é criar um convite de evento diretamente no navegador, personalizar seus dados e baixar o resultado como imagem PNG. O projeto ainda não está finalizado.

## O que já existe

- Prévia de título, local, datas, descrição e contatos.
- Temas claro e escuro e imagem de capa local.
- Exportação de convite como PNG e validação da ordem das datas.

## Como visualizar

Clone o repositório e abra `index.html` no navegador. Para testar por HTTP, use a extensão Live Server do seu editor. Preserve as pastas de CSS, JavaScript e imagens. Não há dependências locais para instalar; recursos de CDN exigem internet.

## Observações

A exportação depende do html2canvas carregado por CDN. Os dados e a imagem escolhida são utilizados no navegador; não existe armazenamento de eventos no backend.
